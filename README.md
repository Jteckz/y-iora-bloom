# Y'IORA Bloom

Design a breathtaking, premium, and emotionally immersive website for "Y'IORA" — a lifestyle events brand for women. The design must feel like a luxury wellness retreat — warm, elegant, playful, and empowering.

Key design directives:

- Use a "living gradient" for the hero — colors shift based on mouse position and time of day.

- Typography: Lora for headings (bold, expressive), Inter for body (clean, modern).

- Color palette: Soft pink (#D4A5A5), blush (#F5E6E6), rose (#B5838D), warm white (#FFF9F7), deep brown (#3A2C2C).

- Layout: Asymmetrical, broken grid — no two sections should look the same.

- Interactivity: Custom cursor, micro-animations on hover, parallax scrolling, floating particles (petals).

- Sections: Hero, About (story timeline), Offerings (interactive circles), Events (3D carousel), Testimonials (floating cards), Gallery (mosaic), Footer (community garden).

- The site should evoke feelings of: curiosity, warmth, empowerment, and exclusivity.

- Mobile: Simplified but beautiful — swipe gestures, touch-friendly.

- Accessibility: High contrast, keyboard navigable, reduced-motion support.

Provide a full visual mockup (or code) that embodies this vision.
